ProDesk Elite Tax System — Portal Build v2

This prototype advances the website shell into an application-style portal foundation.
Included:
- Master Dashboard
- Taxpayer Files view
- Live prototype Taxpayer Case Workspace
- Integrated production-stage tracker
- Required controls and next-action panel
- Audit activity panel
- Taxpayer Data Entry terminology throughout
- Draft PostgreSQL/Supabase-oriented schema for the application backend

Important: This is still a local front-end prototype. It does not yet provide production authentication, secure tax-document storage, payment processing, e-signature, or a deployed database.
